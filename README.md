# One Year of Us

A small, self-contained anniversary website. Open `index.html` in a browser to preview it.

## Make it yours

1. Open `index.html` in any text editor.
2. Find `const OUR_DATE` near the bottom and set the day she accepted your love in `YYYY-MM-DD` format. This is the answer that unlocks the page.
3. Update the anniversary note, memory captions, and sign-off in the HTML to sound like you.
4. Open `index.html` in a browser and click through the questions to preview the page.

The font uses Google Fonts when a connection is available and falls back to system fonts otherwise.

The closing video is loaded from `conclusion.mp4` in the same folder as `index.html`. Keep the file beside the page when sharing or hosting the site. The fixed vinyl player uses `vinyl.png` and `song.mp3`, which must also stay beside `index.html`.

The hero reel uses `reel.mp4` and its preview image `reel-poster.jpg`; keep both beside `index.html` too. The memory cards and letter photo use `IMG_1.jpg`, `IMG_2.JPG.jpeg`, `IMG_3.JPG.jpeg`, and `IMG_long.JPG.jpeg` from that folder.

The five-question form opens a prefilled Gmail compose draft addressed to `mayankraut28@gmail.com` in a new tab; the visitor reviews and sends it there. She needs to be signed in to Gmail in the browser. The video unlocks after all five answers are filled in.
